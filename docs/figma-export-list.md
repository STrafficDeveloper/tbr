# Figma export checklist

Images to export from the Figma design **Hive's Community Website (Copy)** for
The Bikers Ranger site. Each link opens Figma with that exact layer selected.

## How to export each file

1. Open the link. Figma selects the layer. If nothing is highlighted, press
   **Shift + 2** to zoom to the selection.
2. In the right-hand panel, scroll to **Export** and click **+**.
3. Set the **format** and **scale** from the table (e.g. `PNG` and `2x`).
4. Click **Export**, then rename the downloaded file to the name in the
   **Save as** column. The exact names matter: the site picks the files up by name.
5. Some layers sit inside masks. Exporting the layer itself gives the full,
   uncropped image, which is what we want.

If the Export section is missing, the file owner has turned off exporting
for viewers. Ask for edit access or for "Allow viewers to copy, share and
export" to be switched on.

## Where to put the files

Upload all of them to the GitHub repo **strafficdeveloper/tbr**, branch
**`claude/nice-dirac-2upjhc`**, in a folder called **`design-exports/`**
(Port Rider photos go in **`design-exports/port-rider/`**):

- Open https://github.com/strafficdeveloper/tbr/tree/claude/nice-dirac-2upjhc
- **Add file → Upload files**. Before dropping the files, type
  `design-exports/` at the start of the path, or drag the whole folder in.
- Commit directly to `claude/nice-dirac-2upjhc`. Do not create a new branch.
